# Customer Churn Prediction System

An end-to-end Machine Learning application that predicts whether a customer is likely to churn and provides churn probability with key factors influencing the prediction.

## Features

- Customer churn prediction using Random Forest Classifier
- Churn probability estimation
- Feature-based prediction explanation
- Data preprocessing and model pipeline
- Interactive Streamlit web application
- Streamlit Cloud deployment

## Tech Stack

Python, Pandas, NumPy, Scikit-learn, Joblib, Streamlit, Matplotlib

## Model

**Random Forest Classifier**

The model uses customer demographic, service, contract, and billing information to predict customer churn.

## Output

- Churn / Stay prediction
- Churn probability
- Key factors influencing the prediction
